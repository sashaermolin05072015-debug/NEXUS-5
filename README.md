NEXUS5 — самодельный карманный мультитул на базе микроконтроллера ESP32, 
собранный на макетных платах, с цветным TFT-дисплеем, 
тремя кнопками управления, пьезо-буззером и модулем NFC (PN532). Устройство 
имитирует функциональность Flipper 
Zero в бюджетном варианте: беспроводные атаки, сниффинг эфира, 
чтение NFC-меток, плюс встроенные игры и погода.

Проект собирался постепенно: сначала базовое меню и Wi-Fi сканер, потом — пранк-режимы, затем — хакерские инструменты, NFC и, наконец, мини-сайт для NFC-метки.

---

Железо

Компонент Модель Пины
Микроконтроллер ESP32 DevKit (240 МГц, 520 КБ SRAM) —
Дисплей ST7735, 160×128 TFT CS=15, RST=4, DC=2, BL=16
Кнопки 3 тактовые, INPUT_PULLUP BACK=26, NEXT=25, SELECT=14
Буззер Пассивный пьезо GPIO 32 (через LEDC)
NFC PN532 (I2C) SDA=21, SCL=22
Питание USB 5V / Li-Ion —

Корпус — самодельный: три макетные платы (жёлтая, белая, синяя), скреплённые между собой, ESP32 по центру, дисплей спереди, кнопки справа. На корпус приклеена NFC-наклейка, ведущая на мини-сайт проекта.

Программная часть

Язык: C++ (Arduino framework для ESP32)
Ядро: Arduino ESP32 core 3.3.5
Среда: ArduinoDroid (мобильная IDE) + Arduino IDE

Используемые библиотеки

· Adafruit_GFX — графика
· Adafruit_ST7735 — драйвер дисплея
· Adafruit_PN532 — NFC
· WiFi, HTTPClient, NetworkClientSecure — сеть
· WebServer, DNSServer — captive portal
· Wire — I2C для PN532
· SPI — дисплей
· esp_wifi.h — низкоуровневые Wi-Fi функции
· Стандартные time.h, SPI.h

Структура интерфейса

Прошивка построена на конечном автомате экранов (enum Screen). Каждый экран имеет свою tick-функцию, которая вызывается в loop(). Переключение между экранами происходит через изменение переменной screen и флага screenEntered.

Главное меню — в стиле Flipper Zero: одна большая карточка на весь экран, плавный слайд 140 мс при перелистывании, индикатор страниц точками внизу.

Цветовая палитра

Всё в чёрно-оранжевом стиле:

```cpp
#define COL_BG      0x0000  // чёрный
#define COL_ACCENT  0xFC00  // оранжевый
#define COL_ACCENT2 0xFD20  // светло-оранжевый
#define COL_DIM     0x7BEF  // серый
#define COL_TEXT    0xFFFF  // белый
#define COL_WARN    0xF800  // красный
#define COL_OK      0x07E0  // зелёный
```

Режимы устройства

Сетевые (Wi-Fi)

1. Scan Networks — сканирует эфир, показывает SSID, RSSI, канал, тип шифрования. С прокруткой и индикатором позиции.

2. My WiFi — статус текущего подключения: SSID, IP, RSSI.

3. Hotspot — поднимает точку доступа с именем "ты лох:)". Показывает IP и количество подключённых клиентов.

4. Beacon Spam — рассылает фейковые точки доступа с мемными SSID (FBI Surveillance Van, Virus.exe, Get off my WiFi, Pretty Fly for a WiFi, Nacho WiFi, Totally Not A Virus и т.д.). Каждый beacon — со случайным MAC. Каналы перебираются 1→13. Счётчик OK / ERR на экране.

5. Captive Portal — поднимает точку Free WiFi, при подключении клиента открывается страница с большой надписью «ТЫ ЛОШПЕД» (чёрный фон, оранжевый текст). DNS-сервер перехватывает все запросы. Показывает количество клиентов и аптайм.

6. Probe Sniffer — пассивно слушает probe-запросы от телефонов. Показывает MAC + бренд (OUI lookup) + RSSI. Список из 20 устройств с прокруткой. Прыгает по каналам 1/6/11 каждые 5 секунд.

7. Deauth Attack — выбирает цель из списка сетей, шлёт deauth-фреймы. Показывает количество отправленных пакетов. Только для своей территории.

8. WiFi Radar — визуализация сетей на круговом радаре. Чем сильнее сигнал — тем ближе точка к центру. Открытые сети обведены кольцом. Три режима: ALL / OPEN / MY.

9. Deauth Detector — пассивно ловит deauth-фреймы в эфире. Если атака идёт — экран мигает красным, показывается MAC атакующего и его бренд. Ведёт лог последних 10 атак.

10. Karma Attack — отвечает на probe-запросы клиентов, притворяясь сетью, которую они ищут. Ловит до 8 SSID в список, потом может поднять точку с одним из них.

NFC

11. PN532 Reader — читает UID NFC/RFID-меток, определяет тип (MIFARE, NTAG). Ведёт историю последних 5 считанных карт.

Прочее

12. Display Test — цветные блоки и фигуры для проверки дисплея.

13. Dino — аркада. Оранжевый динозаврик, прыгает через кактусы, приседает, уворачивается от птиц. Звёзды, облака с параллаксом, счёт и рекорд. Земля — пунктирная линия ниже кактусов, чтобы ничего не сливалось.

14. Weather — часы и погода. IP-геолокация через ip-api.com, погода через open-meteo.com. Показывает время, дату, температуру, город.

15. Settings — яркость экрана (5 уровней через LEDC на пине 16) и вкл/выкл буззера.

16. Info — короткая справка о плате.
